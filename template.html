Il testo e la guida

Testo CEI 2008 ricavato dall’EPUB fornito dall’utente. La conversione è stata verificata rispetto al file originale. Le particolarità editoriali e di numerazione della fonte sono conservate e documentate qui sotto.

Uso offline e iPhone

Il file contiene tutto il testo, gli stili e il programma: nessuna libreria esterna. La lettura funziona anche senza connessione, in un browser che esegue JavaScript. Su iPhone l’anteprima dell’app File può non eseguire un HTML interattivo: serve un’app/browser che supporti l’apertura di HTML locali. In alternativa ospita il file su un server locale raggiungibile dall’iPhone; il server dovrà restare raggiungibile. Questa versione non installa una PWA e aprirla una volta via web non garantisce l’uso offline successivo. Non è stata verificata su un iPhone fisico.

Nel menu «Apri un passo» il versetto finale è opzionale: «Solo iniziale» seleziona un singolo versetto; scegliendo un finale si seleziona l’intervallo nello stesso capitolo. Riferimenti supportati: «Mt 5», «Mt 5,3», «Mt 5,3-12», «Giovanni 3:16», anche con trattino lungo e lettere, come «Est 1,1a». Gli intervalli devono stare nello stesso capitolo. Per Ester puoi scegliere la versione dal menu o scrivere «Est ebraico 9,30». I Salmi usano il primo numero del titolo; il numero tradizionale fra parentesi resta visibile. La ricerca testuale trova frasi contigue, senza distinzione di accenti o maiuscole, e mostra 60 risultati per volta.

Importa un altro dataset

Sono accettati dataset JSON nel formato numerico qui sotto (schema 1), oppure nel formato schema 2 di questo progetto, che conserva etichette alfabetiche, varianti e ordine della fonte. Nessuna conversione automatica da PDF, EPUB, XML o altre strutture JSON. I nomi e la numerazione restano quelli del dataset importato. L’importazione sostituisce la traduzione visualizzata, non trasferisce i segnalibri fra traduzioni.

{
  "schemaVersion": 1,
  "id": "mia-traduzione-v1",
  "title": "Nome della traduzione",
  "language": "it",
  "license": "Licenza o autorizzazione ricevuta",
  "source": "Provenienza del testo",
  "books": [{
    "id": "MAT", "name": "Matteo",
    "aliases": ["Mt"], "testament": "NT",
    "chapters": {"5": [
      {"verse": 3, "text": "Testo autorizzato"}
    ]}
  }]
}

Il dataset viene conservato nel browser se possibile. Per mantenerlo indipendente dallo spazio del browser usa «Scarica HTML con il testo attuale». Un file scaricato conterrà integralmente il testo importato: condividilo solo se la relativa licenza lo consente.
